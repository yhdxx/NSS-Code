# myCodingAgent 函数级项目框架图

> 本文档用于在修改代码时同步维护项目结构认知。未来每次代码变更后，应同时更新本文件中对应的模块、类、函数和职责说明。

## 1. 项目总览

- 项目：`myCodingAgent`
- 定位：基于 LLM 的命令行编码智能体，在 Docker 沙箱中执行文件读写、搜索、Shell 命令，并通过 Skill 系统扩展领域工作流。
- 核心链路：`__main__.py` 启动 CLI -> `client.py` 调用模型 -> `tools/` 执行工具 -> `memory/` 管理长上下文 -> `skills/` 动态检索并暴露专业能力。
- 当前索引范围：Python/TypeScript/JavaScript 代码文件；Markdown、JSON、CSS、模板等资源在 Skill 资产章节按目录归纳。
- 生成依据：README 项目说明、核心源码定向阅读、AST/正则提取的类与函数索引。

## 2. 顶层架构图

```text
myCodingAgent
├── 入口层：__main__.py
│   ├── main()：初始化 Docker、工具、Skill、Memory、命令系统并进入交互循环
│   ├── build_command_registry()：注册 /resume、/fork、/clear 与 /delete
│   └── handle_*_command()：会话恢复、分叉、清空、删除、选择与确认
├── 模型交互层：client.py
│   ├── ask_deepseek()：单轮用户请求的模型-工具循环
│   ├── PromptDebug / TokenUsage：DEBUG=true 时输出 prompt 分区哈希；始终输出本轮与会话 token 汇总
│   ├── stream_chat_completion()：流式读取模型响应
│   ├── execute_tool_call()：解析并执行工具调用
│   └── format/pretty/helper 函数：工具 schema、参数、输出展示
├── 配置与状态层：config.py / cache.py / workspace_identity.py / session_switch.py
├── 命令系统：commands/
├── 工具系统：tools/
├── 记忆系统：memory/
├── Skill 系统：skills/
├── 测试：tests/
└── 资源与文档：README.md、Dockerfile.sandbox、requirements*.txt、各 Skill 的 SKILL.md/references/assets/scripts
```

## 5. 关键运行流程

### 5.1 启动与交互

```text
用户执行 myAgent
└── __main__.main()
    ├── get_docker_image() / ensure_docker_image()
    ├── FileStateCache + WorkspaceChangeTracker.start()
    ├── MemoryRuntime(...) 初始化会话记忆与清理过期会话
    ├── create_default_registry(...) 注册基础工具
    ├── SkillRuntime.initialize() 同步并注册 Skill 工具
    ├── build_command_registry() 注册 /resume、/fork、/clear、/delete
    └── while True: read_user_prompt() -> 命令分发或 client.ask_deepseek()
```

### 5.2 模型工具调用

```text
client.ask_deepseek()
├── 构造/追加用户消息
├── 固定 system prompt 执行 Work Context Sufficiency Protocol / Evidence First Rule
├── RuntimeContextBuilder() 收集当前轮 workspace/budget/snapshot/recovery hint
├── PromptRenderer.render_current_user_message() 生成非持久化 RenderedPrompt
├── build_round_tools() 每个用户轮构造一次 tools，同一用户轮内复用
├── MemoryRuntime.render_messages_for_model() 压缩/虚拟化历史，不插入动态 system
├── render_current_turn_for_model() 仅在模型视图中把当前 user 替换为 RenderedPrompt
├── SkillRuntime.select_tools_for_prompt() 每个用户轮动态选择 Skill
├── build_prompt_debug_snapshot() 按 fixed/temporary/historical/runtime_context/current/tools 分区估算 token 与 hash
├── DEBUG=true 时 print_prompt_debug_with_previous() 打印首个变化分区并用分隔线包裹 PromptDebug
├── stream_chat_completion() 读取流式 assistant 输出；模型按需判断 working context 是否充足
├── api_usage_to_dict() 解析 provider usage 并打印单次请求 token
├── MemoryRuntime.record_token_usage() 持久化单次请求 token 与 prompt/tools hash
├── 如果存在 tool_calls: execute_tool_call()
│   └── ToolRegistry.execute() -> 具体工具 run()，可多轮 Search/Recover 历史证据
├── MemoryRuntime.save_tool_output() 保存可恢复工具输出
├── 持久化历史只保存原始 user query；RenderedPrompt/RuntimeContext 不写入历史
├── 循环直到模型认为证据充足并 finish_reason=stop，或达到 MAX_TOOL_ROUNDS
└── print_turn_token_summary() 输出本轮与会话累计 token
```

### 5.3 长上下文与会话恢复

```text
MemoryRuntime
├── PromptBudgetManager 估算 token 压力阶段
├── ContextCompressor 截断/指针化工具输出
├── WorkingContext 保存 RecoverableContextObject
├── CheckpointManager 生成 ConversationSnapshot
├── SQLiteMemoryStore.session_token_usage 持久化 TokenUsageRecord
├── load_session() 恢复消息、快照、工作区状态和 TokenUsageSummary
└── await_pending_rollover()/on_turn_completed() 在高压时翻转会话
```

### 5.4 Skill 路由

```text
SkillRuntime.initialize()/sync()
├── discover_skills() 扫描 SKILL.md 与 references
├── SkillStore 保存 SkillRecord/ReferenceRecord
├── SkillVectorStore + EmbeddingProvider 建立语义索引
├── SkillRouter 融合向量结果、用户 LRFU、会话 LRFU、固定 Skill
├── skills/tools.py 注册 search_tool/Get_skill_reference 等管理工具
└── record_skill_invocation() 更新调用反馈与 LRFU
```
